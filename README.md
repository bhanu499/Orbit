# Orbit — Android AI Agent App (Demo Mode)

## Build & Install on Your Phone (No Laptop Required)

1. Create a new repository on GitHub (public = unlimited free Actions minutes; private = 2,000 free minutes/month).
2. Unzip `Orbit-Android.zip` and upload the **contents** of the `Orbit/` folder to the root of your repository (make sure `.github/workflows/build.yml` is at the top level).
3. Open the **Actions** tab in your repository and run **Build Orbit Debug APK** (or it will start automatically on push).
4. Once the build finishes (~3–5 minutes), open the completed run, scroll to **Artifacts**, and download **orbit-debug-apk**.
5. Unzip the downloaded artifact on your OnePlus 13 and tap `app-debug.apk` to install.
